# Политика конфиденциальности

**Приложение:** Шумовой сигнал (NoiseAlert)
**Дата вступления в силу:** 26 сентября 2026 года

## Коротко

Приложение не собирает, не хранит и не передаёт никакие данные. Всё, что оно
делает, происходит на вашем устройстве.

## Какие данные обрабатываются

**Звук с микрофона.** Пока мониторинг запущен, приложение непрерывно получает
аудиопоток с микрофона, чтобы измерять уровень громкости. Из каждого буфера
вычисляется единственное число — среднеквадратичный уровень в дБFS. Сам звук
при этом не записывается, не сохраняется и никуда не отправляется: буфер
обрабатывается в оперативной памяти и сразу отбрасывается.

**Настройки.** Порог срабатывания, длительность сигнала и включённые каналы
сохраняются локально в хранилище настроек приложения на вашем устройстве.
Эти данные никуда не передаются.

**Журнал работы.** Приложение ведёт локальный технический журнал (время
запуска, параметры аудиосессии, факты срабатывания сигнала). Журнал хранится
только в папке приложения на устройстве, ограничен по размеру и не содержит
записей звука. Он используется для диагностики и удаляется вместе с
приложением.

## Чего приложение не делает

- Не передаёт данные по сети — приложение вообще не использует сеть
- Не запрашивает доступ к геолокации, контактам, фотографиям, календарю
- Не использует аналитику, рекламу и сторонние SDK
- Не создаёт учётных записей и не требует регистрации
- Не отслеживает вас между приложениями и сайтами

## Разрешения

**Микрофон.** Требуется для основной функции — измерения уровня шума.
Предоставляется вами и может быть отозвано в любой момент в
«Настройки → Шумовой сигнал».

**Уведомления.** Требуются, чтобы система мигнула светодиодной вспышкой при
срабатывании сигнала на заблокированном экране. Уведомления формируются
локально на устройстве.

Пока идёт прослушивание, iOS показывает оранжевый индикатор микрофона. Вы
всегда можете видеть, что приложение работает, и остановить его одной кнопкой.

## Дети

Приложение не предназначено для сбора каких-либо данных и не собирает их
ни от кого, включая детей младше 13 лет.

## Изменения политики

При изменении политики обновлённая версия будет опубликована по этому же
адресу с новой датой вступления в силу.
